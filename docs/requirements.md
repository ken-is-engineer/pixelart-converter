# 要件

GIF を入力に、デスクトップ GUI で MP4 / JPEG / PNG / GIF へ変換するアプリケーションの要件。ピクセルアート用途を前提とし、リサイズは画質劣化を抑える。

## 1. 目的

- 単一の GIF ファイルを、指定した形式・サイズ・オプションで書き出す
- macOS / Windows 向けに、FFmpeg を同梱した単体アプリとして配布する
- 依存ライブラリのライセンス制約（特に FFmpeg の GPL トリガー）を満たしたまま H.264 / MP4 を出力する

## 2. スコープ

### 2.1 対象

- 入力: GIF のみ（1 ファイル）
- 出力: MP4 / JPEG / PNG / GIF
- GUI: PySide6 による単一ウィンドウ
- 配布: PyInstaller による macOS `.app` と Windows `.exe`
- FFmpeg: アプリに LGPL ビルドを同梱（ユーザーが別途インストールする必要はない）

### 2.2 非スコープ（当面やらない）

- 動画（MP4 等）や静止画を入力にすること
- フォルダ単位のバッチ変換
- Web 版 / CLI 専用製品（内部的な CLI ラッパは実装してよい）
- GPL ビルドの FFmpeg、`libx264` の同梱
- VP9 / AV1 / WebM（将来選択肢として残す。拡張子は当面 `.mp4`）
- コード署名・公証の本番運用（後続タスク）

## 3. 機能要件

### 3.1 入力

| ID | 要件 |
|----|------|
| F-IN-1 | 入力は GIF ファイル 1 つとする |
| F-IN-2 | ファイル選択ダイアログ、またはパス指定で入力できる |
| F-IN-3 | 開けない・破損している GIF は変換せず、理由が分かるエラーを出す |

### 3.2 出力形式

| ID | 要件 |
|----|------|
| F-OUT-1 | 出力形式は MP4 / JPEG / PNG / GIF から 1 つ選ぶ |
| F-OUT-2 | 出力パス（ファイル名）を指定できる。未指定時は入力名から妥当なデフォルトを付ける |

### 3.3 MP4

| ID | 要件 |
|----|------|
| F-MP4-1 | ループ回数 **または** 再生秒数のいずれかを指定して出力する（同時指定はしない。UI 上は排他） |
| F-MP4-2 | ループ回数は「GIF を何周分つなぐか」を意味する。1 以上の整数 |
| F-MP4-3 | 秒数指定時は、指定秒数になるまで GIF を繰り返し、足りない場合は途中で切る |
| F-MP4-4 | 映像コーデックは H.264。コンテナ拡張子は `.mp4` |
| F-MP4-5 | エンコーダーは OS ネイティブのハードウェアを優先する（後述ライセンス） |

### 3.4 JPEG / PNG

| ID | 要件 |
|----|------|
| F-IMG-1 | 出力するフレームを指定できる |
| F-IMG-2 | 指定方法は次の 3 種とする: **単一フレーム**（0 始まりのインデックス）、**複数フレーム**（カンマ区切りまたは範囲 `start-end`）、**全フレーム** |
| F-IMG-3 | 単一フレームは 1 ファイル（指定した出力ファイル名） |
| F-IMG-4 | 複数・全フレームは連番ファイルとする。出力ファイル名の stem に連番を付ける（例: `out_000.png`） |
| F-IMG-5 | 存在しないフレーム番号はエラーとし、部分出力しない |

### 3.5 GIF 再出力

| ID | 要件 |
|----|------|
| F-GIF-1 | リサイズやメタデータ削除など、再エンコードが必要な場合は GIF として書き出す |
| F-GIF-2 | アニメーション（フレーム遅延）は入力を可能な範囲で維持する |

### 3.6 全出力共通

| ID | 要件 |
|----|------|
| F-CMN-1 | 出力サイズ（幅・高さ、ピクセル）を指定できる |
| F-CMN-2 | 未指定時は入力 GIF のピクセルサイズを維持する |
| F-CMN-3 | リサイズの既定アルゴリズムは nearest-neighbor（ピクセルアート向け）。必要なら bilinear / bicubic も選べるようにする |
| F-CMN-4 | メタデータ削除の有無を選べる。オン時はコメント・XMP 等を出力に残さない |
| F-CMN-5 | 変換中は進捗が分かり、キャンセルできる |
| F-CMN-6 | 変換失敗時は、ユーザーが対処できるメッセージを出す（エンコーダー非対応、ディスク不足、パス不正など） |

## 4. 非機能要件

| ID | 要件 |
|----|------|
| N-1 | 対象 OS: macOS、Windows（いずれも現行のサポート対象バージョンを前提） |
| N-2 | ランタイムとして別途 Python / FFmpeg をインストールさせない。PyInstaller 成果物に同梱する |
| N-3 | FFmpeg は subprocess で呼び出す。自社コードから FFmpeg をライブラリリンクしない |
| N-4 | GUI は変換中も固まらない（変換はワーカースレッド） |
| N-5 | 同梱 FFmpeg は LGPL ビルドに限り、配布物にライセンス文書とソース提供方法を含める |

## 5. ライセンス・コンプライアンス

必須制約。実装・配布で破ってはならない。

### 5.1 PySide6

- ライセンス: LGPL v3
- 動的リンクのため、自社コードは非公開（プロプライエタリ）のままでよい
- 配布時は PySide6 / Qt の LGPL 通知と、利用者が Qt を差し替えられる状態（動的リンク）を維持する

### 5.2 FFmpeg

- **LGPL ビルドのみ**を同梱・配布する
- GPL をトリガーする `libx264`（H.264 ソフトウェアエンコーダー）は **組み込まない**
- 市販・公開の “full” FFmpeg バイナリは x264 入り GPL が多い。同梱物は **GPL なし・libx264 なし**で自前ビルドするか、LGPL であることが明示されたビルドに限る
- 配布物に FFmpeg のライセンス文書（LGPL）と、対応するソースコードの提供方法を含める

### 5.3 H.264 / MP4

特許と GPL を避けるため、MP4 の H.264 は OS ベンダーのハードウェアエンコーダーを使う。

| OS | FFmpeg エンコーダー |
|----|---------------------|
| macOS | `h264_videotoolbox` |
| Windows | `h264_mf`（Media Foundation） |

これにより GPL 回避と、H.264 特許リスクを OS ベンダー側に委ねる。

### 5.4 ソフトウェアフォールバック（T2-4 確定）

**現行ビルドではソフトウェア H.264 フォールバックを採用しない。** T2-4 の検証時点で Cisco OpenH264（`libopenh264`）は同梱 configure に含めていない。理由:

- `vendor/ffmpeg/build_flags.txt` に `--enable-libopenh264` が無い
- OpenH264 の対応プロファイル（Constrained Baseline か Main か）を実機で未検証
- 検証用バイナリがビルド環境に存在しない

方針:

- MP4 の H.264 は **OS ネイティブ HW エンコーダーのみ**（§5.3）。ソフトウェア H.264 エンコーダーは同梱・使用しない
- 同梱 FFmpeg に `libx264` が載っていても **使用しない**（GPL 回避）
- システム PATH の `ffmpeg` や GPL ビルドへ **黙って切り替えない**
- HW エンコーダーが使えない環境では MP4 出力を **失敗** とし、理由を表示する

将来 OpenH264 を採用する場合は、実機でプロファイルを検証したうえで `--enable-libopenh264` を configure に追加し、本要件と設計を更新する。

### 5.5 その他依存

| ライブラリ | ライセンス | 配布上の扱い |
|------------|------------|--------------|
| Pillow | MIT-CMU | 制約なし（通知は推奨） |
| PyInstaller | GPL + linking exception | 成果物へのリンク例外あり。PyInstaller 自体のソース提供義務は通常発生しない |

### 5.6 コンテナ・将来

- 拡張子は当面 `.mp4` を維持する
- 将来の選択肢として VP9 / AV1（WebM）への切り替えを残す。本バージョンの必須要件ではない

## 6. 用語

| 用語 | 意味 |
|------|------|
| ループ回数 | 入力 GIF を先頭から何周分つなぐか |
| 秒数 | 出力 MP4 の再生時間。GIF を繰り返して埋める |
| フレームインデックス | 0 始まり。先頭フレームが 0 |
| 同梱 FFmpeg | アプリ配布物に含める LGPL ビルドの `ffmpeg` 実行ファイル |
